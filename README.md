# EcoTech Solutions - Trabajo Práctico Final

## Instalación
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Ejecución
- Ejercicio 1: `python ejercicio1/sensores.py`
- Ejercicio 2: `python -m ejercicio2.demo`
- Ejercicio 3 (tests): `python -m unittest sustentabilidad.test_emisiones -v`
- Ejercicio 3 (web): `python manage.py runserver` y abrir `http://127.0.0.1:8000/sustentabilidad/panel/`
